# 자산관리

예금·주식·부동산·연금·가상자산·부채를 한곳에 등록하고, 평가액을 주기적으로 기록해 순자산 추이와 자산 배분을 보는 로컬 웹앱.

## 실행

```bash
npm install
npm run dev        # http://localhost:5180 (Vite 개발 서버 내장)
```

배포용:

```bash
npm run build
npm start          # dist/ 를 서빙
```

Node 22.13 이상 필요 (내장 `node:sqlite` 사용). 서버는 127.0.0.1 에만 바인딩되어 이 PC 에서만 접속된다.

## 화면

상단 **보기** 선택으로 가구 전체 / 사람별 / 공동 명의를 오가며 모든 화면이 그 범위로 바뀐다.

- **대시보드** — 순자산·총자산·총부채, 전월/1년 변화, 사람별 순자산(가구 전체 보기), 월별 순자산 추이, 카테고리별 배분(목표 대비), 목표 달성률
- **자산·부채** — 항목 등록/수정/삭제, 명의(사람 또는 공동), 카테고리별 소계, 항목별 평가 이력
- **평가액 기록** — 기준일을 정해 보이는 범위의 모든 항목 평가액을 한 번에 입력 (마지막 값이 미리 채워짐, 같은 날짜는 덮어씀)
- **사람·목표·배분** — 가구 구성원 추가/이름 변경/삭제, 가구 또는 개인 순자산 목표, 카테고리별 목표 비중, JSON 백업/복원

명의가 없는 자산은 '공동'으로 집계되고 가구 전체에만 합산된다(지분 나누기는 하지 않음). 명의 자산·목표가 남아 있는 사람은 삭제할 수 없다.

## 데이터

- `data/assets.db` (SQLite). 위치는 `ASSET_DATA_DIR` 환경변수로 바꿀 수 있다. git 에는 올라가지 않는다.
- 순자산 추이는 월말 기준이며, 기록이 없는 달은 직전 평가액이 유지된 것으로 계산한다.
- 부채는 양수로 입력하고 순자산 계산 시 차감한다.

## 구조

```
server/   Express API + SQLite (api.js, calc.js 요약 계산, sample.js 샘플 데이터)
shared/   카테고리 정의 (서버·화면 공용)
src/      React 화면 (views/), 차트 (charts/)
```

테스트: `npm test`
