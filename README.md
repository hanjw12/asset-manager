# 자산관리

예금·주식·부동산·연금·가상자산·부채를 한곳에 등록하고, 평가액을 주기적으로 기록해 순자산 추이와 자산 배분을 보는 웹앱. 서버 없이 브라우저에서만 동작해서 GitHub Pages 로 배포하고 휴대폰·PC 어디서나 URL 로 연다.

## 데이터 저장

처음 열면 저장 위치를 고른다.

- **GitHub 비공개 저장소 (기기 간 동기화)** — 데이터 전체가 비공개 저장소의 JSON 파일 하나(기본 `assets.json`)에 저장된다. 저장할 때마다 커밋이 남아 변경 이력이 곧 백업이다. 휴대폰과 PC에서 같은 저장소를 연결하면 같은 데이터를 보고, 화면으로 돌아올 때마다 최신 내용을 다시 불러온다. 다른 기기가 먼저 저장했으면 덮어쓰지 않고 최신 데이터를 불러온 뒤 다시 시도하라고 알린다.
- **이 기기에만 저장** — 브라우저 저장소(localStorage)에만 둔다. 브라우저 데이터를 지우면 사라지므로 JSON 백업을 받아 둔다.

### GitHub 연결 준비

1. 데이터용 **비공개** 저장소를 만든다 (예: `asset-manager-data`). 공개 저장소는 연결을 거부한다.
2. [Fine-grained 토큰](https://github.com/settings/personal-access-tokens/new)을 만든다.
   - Repository access: **Only select repositories** → 데이터 저장소 하나만
   - Repository permissions → **Contents: Read and write**
3. 앱에서 저장소(`아이디/저장소`)와 토큰을 입력한다. 기기마다 한 번씩.

토큰은 그 기기 브라우저(localStorage)에만 저장되고 `api.github.com` 외에는 보내지 않는다. 같은 `<아이디>.github.io` 주소의 다른 Pages 사이트도 같은 브라우저 저장소를 볼 수 있으니, 이 주소에는 믿을 수 있는 사이트만 올린다. 기기를 잃어버리면 GitHub 설정에서 토큰을 삭제한다.

## 실행·배포

```bash
npm install
npm run dev        # http://127.0.0.1:5180
npm test
npm run build      # dist/
```

`.github/workflows/pages.yml` 이 `main` 에 push 될 때마다 테스트·빌드 후 GitHub Pages 에 배포한다. 저장소 설정의 Pages 소스를 **GitHub Actions** 로 둔다.

예전 로컬 서버 버전(SQLite)을 쓰던 데이터는 그 버전에서 JSON 백업을 받아 **사람·목표·배분 → 백업 파일로 복원** 으로 옮긴다.

## 화면

상단 **보기** 선택으로 가구 전체 / 사람별 / 공동 명의를 오가며 모든 화면이 그 범위로 바뀐다.

- **대시보드** — 순자산·총자산·총부채, 전월/1년 변화, 사람별 순자산(가구 전체 보기), 월별 순자산 추이, 카테고리별 배분(목표 대비), 목표 달성률
- **자산·부채** — 항목 등록/수정/삭제, 명의(사람 또는 공동), 카테고리별 소계, 항목별 평가 이력
- **평가액 기록** — 기준일을 정해 보이는 범위의 모든 항목 평가액을 한 번에 입력 (마지막 값이 미리 채워짐, 같은 날짜는 덮어씀)
- **사람·목표·배분** — 가구 구성원 추가/이름 변경/삭제, 가구 또는 개인 순자산 목표, 카테고리별 목표 비중, 저장 위치·JSON 백업/복원

명의가 없는 자산은 '공동'으로 집계되고 가구 전체에만 합산된다(지분 나누기는 하지 않음). 명의 자산·목표가 남아 있는 사람은 삭제할 수 없다. 순자산 추이는 월말 기준이며, 기록이 없는 달은 직전 평가액이 유지된 것으로 계산한다. 부채는 양수로 입력하고 순자산 계산 시 차감한다.

## 구조

```
shared/   데이터 문서 규칙 (store.js 검증·수정, calc.js 요약 계산, sample.js 샘플)
src/      React 화면 (views/), 차트 (charts/), api.js 문서 관리, storage.js 브라우저·GitHub 저장소
```
